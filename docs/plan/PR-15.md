# PR-15: RePoE data replacement #2-#5 and multilingual search

> 상위 문서: [../pob-handoff.md](../pob-handoff.md)
> 원천 항목: handoff RePoE 데이터 점진 대체
> 선행 PR: [PR-14](PR-14.md)
> 후속 PR: [PR-16](PR-16.md) (Passive tree precision)

## 목표

PR-10 의 passive tree text override 패턴을 확장해 시즌 전 필요한 RePoE 데이터 점진 대체 #2~#5 를 진행한다. 설정 언어가 한국어이면 인게임 데이터 영문 표기를 RePoE 기준 한국어로 표시하고, 검색은 설정 언어와 영어 모두에서 같은 대상을 찾도록 한다.

PoB Lua 계산과 build-code 호환에 필요한 원본 ID / 영문 identifier 는 변경하지 않는다.

계획 문서 관리 규칙에 따라 이 문서는 코드 커밋에 포함하지 않고 unstaged 상태로 둔다.

## 범위

- #2 stat description templates
- #3 unique item names / descriptions
- #4 gem / skill descriptions
- #5 mod text
- 설정 언어 기준 표시
- 모든 표시 언어에서 영어 검색 fallback
