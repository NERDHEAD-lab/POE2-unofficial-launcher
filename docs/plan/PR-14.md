# PR-14: Legacy/Renewed UI mode foundation

> 상위 문서: [../pob-handoff.md](../pob-handoff.md)
> 원천 항목: [PR-ELSE](PR-ELSE.md) Legacy/Renewed UI Mode
> 선행 PR: [PR-13](PR-13.md)
> 후속 PR: [PR-15](PR-15.md) (RePoE data replacement)

## 목표

비공식 PoB wrapper title 오른쪽에 `Legacy` / `Renewed` 전환 스위치를 추가하고, 두 UI 가 같은 PoB source snapshot 과 action payload 를 소비하도록 facade 경계를 만든다.

Legacy 는 PoB 원본 UI 성격을 최대한 따르는 모드이고, Renewed 는 현재 개선 UI 를 유지하는 모드다. Lua 원본 값이나 identifier 는 UI facade 밖에서 번역/변형하지 않는다.

계획 문서 관리 규칙에 따라 이 문서는 코드 커밋에 포함하지 않고 unstaged 상태로 둔다.
