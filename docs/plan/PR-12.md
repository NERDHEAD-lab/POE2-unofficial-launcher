## Context Notes

- `ImportTab.lua` 원본은 Character Import 를 PoE OAuth/API 인증(`PoEAPI`, auth token, character list/download)으로 처리한다.
- Build Sharing 원본 controls: Generate, Export Support, Copy, export site dropdown, Share, import code/URL input, import mode dropdown(`Import to this build`, `Import to a new build`, `Import as comparison`), Import.
- Export Support 는 원본에서 `self.build.partyTab.enableExportBuffs = state` 와 `buildFlag = true` 로 연결되고, Load/Save 는 `exportParty` attrib 로 왕복한다.
- URL Share / URL Download 는 `BuildSiteTools.lua` 의 외부 사이트 업로드/다운로드(`Maxroll`, `POBBin`, `PoeNinja`, `PoE2DB`, `Pastebin`, `Rentry`)에 의존한다. 이번 sub-step 은 네트워크를 새로 연결하지 않고 typed unsupported 상태로 노출했다.
- Comparison import 는 `CompareTab:ImportBuild(xml, "Imported comparison")` 를 사용하되 wrapper action 에서는 현재 build-code export 가 변하지 않도록 BUILD `viewMode` 를 변경하지 않는다.
