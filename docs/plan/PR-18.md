## 목표

BuildListView / Build Explorer 의 Explorer식 조작성을 보강한다. 현재 row hover 옵션 버튼 흐름은 유지하면서 우클릭 메뉴를 같은 action menu 에 연결하고, 컨텍스트 메뉴 아이콘과 목록 메타 표시 정책을 정리한다.

계획 문서 관리 규칙에 따라 이 문서는 코드 커밋에 포함하지 않고 unstaged 상태로 둔다.

## Context Notes

- [x] Build Explorer 는 `Sidebar.tsx` 의 recursive `renderTreeNode` 가 folder/file row 를 렌더링하고, `menuItem` 상태가 hover more button 메뉴와 keyboard shortcut action 을 함께 제어한다.
- [x] file 메뉴 순서는 Copy, Cut, Rename, Delete 이며 folder 메뉴는 New Folder, Paste(clipboard 있을 때만), Rename, Delete 이다. PR-18 은 `sidebarMenuActions.ts` 로 이 순서를 descriptor 화하고 테스트로 고정했다.
- [x] 우클릭은 folder/file row 의 `onContextMenu` 에서 browser context menu 를 막고 기존 `menuItem` 을 설정한다. hover more button, keyboard shortcut, focus-within fallback 은 유지했다.
- [x] 원본 PoB `Modules/BuildListHelpers.lua` 는 `<Build>` 태그의 `level`, `className`, `ascendClassName` 만 scan/sort 대상으로 읽는다. wrapper `BuildEntry` 도 현재 `level`, `className`, `ascendClassName` 만 가진다.
- [x] `PlayerStat` / DPS 는 build XML 에 cached stat 으로 저장될 수 있지만 목록 scan source of truth 가 아니며 stale 가능성이 있다. PR-18 에서는 목록에 표시하지 않고, 필요 시 wrapper extension 으로 별도 contract/갱신 시점 정의 후 진행한다.
