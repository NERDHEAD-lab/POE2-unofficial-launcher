## Decisions / Risks

- [x] Canvas 2D 는 PoB 의 반복 texture coordinate 를 그대로 재현하지 못한다. line connector 의 texture 좌표가 1보다 큰 경우에는 quad 전체에 stretch 되도록 0..1 clamp 를 적용했다. 추후 픽셀 단위 visual regression 이 필요하면 WebGL/canvas texture path 를 별도 검토한다.
- [x] 원본에는 `AzmeriAscendancyMiddle` 보조 표시 분기가 있으나 현재 0_4 tree asset map 에서 해당 자산을 확인하지 못했다. PR-16.3 에서는 기존 `AscendancyMiddle` diamond 와 overlay/activeEffect state parity 만 보강하고, 별도 자산이 들어오면 follow-up 으로 추가한다.
- [x] PR-16.4 는 새 IPC/EventBus 채널을 추가하지 않았다. 기존 `pob.tree.snapshot` RPC payload shape 만 typed contract 로 확장했으며, dependency connector image tint 는 Canvas 2D 한계상 textured connector 위 red stroke overlay 로 근사한다.
- [x] PR-16.5 의 mastery popup 과 Find Timeless Jewel 은 현 PR 에서 직접 구현하지 않는 것이 원본 parity 원칙과 충돌하지 않는다. Find Timeless Jewel 은 원본 버튼도 비활성 주석 상태이며, mastery 는 별도 action contract/UX PR 로 분리하는 편이 안전하다.
