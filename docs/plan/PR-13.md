## 목표

PoB 원본 `Notes` mode 를 `Tree / Skills / Items / Calcs / Party` 오른쪽에 추가하고, wrapper 고유 확장으로 Markdown viewer 와 note template 관리 기능을 제공한다.

PoB 원본 notes 데이터는 훼손하지 않고, Markdown/template 기능은 UI facade 와 wrapper namespace 에만 둔다.

계획 문서 관리 규칙에 따라 이 문서는 코드 커밋에 포함하지 않고 unstaged 상태로 둔다.

## Context Notes

- `Build.lua` 원본은 `modeNotes` 버튼, `notesTab = new("NotesTab", self)`, `savers["Notes"]`, `notesTab.modFlag` 기반 unsaved 판단을 가진다.
- `NotesTab.lua` 원본은 `controls.edit.buf` 를 `<Notes>` 텍스트로 저장하며, `showColorCodes` 토글은 `^xRRGGBB`/`^N` 과 `^_xRRGGBB`/`^_N` 사이를 변환한다.
- 원본 색상 버튼은 normal/magic/rare/unique, fire/cold/lightning/chaos, strength/dexterity/intelligence/default 순서다.
- Imported Build2 fixture 의 `<Notes>` 는 공백/빈 텍스트 구조이며, Lua snapshot 에서 `text.trim() === ""` 로 검증했다.
- Markdown 렌더러는 기존 의존성 `marked` + `dompurify` 를 재사용했으며 새 dependency 는 추가하지 않았다.
- Note template 은 AppConfig 를 추가하지 않고 wrapper UI namespace 의 `localStorage` key `pobWrapper.notes.templates.v1` 에 사용자 템플릿만 저장한다.
