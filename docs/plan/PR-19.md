## 목표

사용자 피드백으로 들어온 PoB wrapper UI 잔여작업을 실제 구현 가능한 sub-step 으로 쪼개 처리한다.

계획 문서 관리 규칙에 따라 이 문서는 코드 커밋에 포함하지 않고 unstaged 상태로 둔다.

- `docs/current-plan.md` 의 잔여작업을 이 문서로 승격했다. current-plan 은 inbox 이므로 라우팅 후 비웠다.
- PR-19 는 여러 UI 잔여작업을 포함하되, 코드 커밋은 sub-step 단위로 작게 나눈다.
- Tree/Items/Skills/Calcs/Config 에서 표시 번역을 보강하더라도 PoB Lua 가 원본 ID/영문 identifier 를 기대하는 입력에는 번역 문자열을 보내지 않는다.
- Items tooltip 디자인은 PoB 원본/게임 스타일에 맞추되, 원본 tooltip payload 의 순서와 blank/unavailable 상태를 바꾸지 않는다.
- PR-19.1 에서 리소스 로딩 후 textured connector path 로 전환되며 fallback stroke 가 사라지는 회귀를 보정했다. Normal/Intermediate textured connector 는 보강 stroke 를 유지하고, 비할당 node icon opacity 를 낮춰 선택/미선택 구분을 복구했다.
- PR-19.2 에서 Items hover tooltip 을 `document.body` portal 기반 fixed tooltip 으로 옮겼다. 패널 overflow clipping 을 피하고, viewport flip/max-height 정책과 cursor-follow 위치 갱신을 추가했다.
- PR-19.3 에서 Calcs snapshot/breakdown 표시 텍스트도 RePoE overlay 를 타도록 연결했다. `BuildEditView` 는 `repoeTranslations` 를 `CalcsView` 로 넘기고, `CalcsView` 는 action index/value 와 breakdown key 는 원본 그대로 유지한 채 표시용 snapshot/breakdown 만 번역한다.
- Config 탭의 option/section/list label 은 `ipc_bridge.lua` 가 PoB Lua `Modules/ConfigOptions` 원본 label 을 그대로 전달한다. 확인한 PoB2-KR 로컬 원본도 ConfigOptions label/list 가 영어이고, RePoE 데이터에도 Configuration option label source 는 없다. 따라서 PR-19.3 에서는 한국어 UI chrome 의 `Configuration` 두 곳을 `설정` 으로 보정하고, option label 대량 번역은 source 선정 전까지 하지 않는다.
- PR-19.4 에서 사이드바 빌드 목록/메인 스킬 패널의 기본 높이 비율을 50:50 으로 맞추고, 수동 리사이즈 뒤에도 viewport height 변경 시 비율을 유지하도록 변경했다.
- PR-19.4 에서 Build editor header 에 저장 icon button 을 추가했다. 변경 사항이 없거나 아직 로드되지 않았으면 비활성화되며, draft 저장 시 현재 target/history 를 저장된 파일명으로 갱신한다.
- PR-19.4 에서 빌드명을 input 으로 바꾸고 기존 `builds.renameBuild` API 로 파일명을 즉시 rename 하도록 연결했다. 신규 unsaved draft 는 아직 파일명이 없으므로 input 은 저장 전까지 비활성화된다.
- PR-19.4 에서 Renewed/Legacy UI mode switch 를 언어 선택 옆으로 이동하고, Tree~Notes mode tab 은 줄바꿈 대신 horizontal scroll + pointer drag scroll 로 이동하도록 변경했다.
- 2026-05-28 `docs/current-plan.md` 에 새로 들어온 Tree 할당/연결선 표시 회귀와 mode tab 클릭/스크롤 회귀는 사용자 우선순위 잔여작업이므로 PR-19.5 로 승격했다. 기존 Notes template UX 와 window controls 는 각각 PR-19.6, PR-19.7 로 밀었다.

- PR-19.16 에서 export modal 이 열렸을 때 준비된 import/export snapshot 기준으로 build code 를 자동 생성하도록 연결했다. Export Support 옵션 변경은 snapshot revision/key 변경으로 자동 재생성되며, 수동 생성 버튼은 제거하고 복사 버튼은 icon button 으로 정리했다.

- PR-19.18 에서 Korean item copy parser 자체는 이미 RePoE stat translation 을 통해 한국어 stat line 을 English PoB item text 로 되돌리는 구조였음을 확인했다. 누락된 부분은 custom item 생성 UI 가 현재 언어 힌트를 넘기지 않고, parse-and-add IPC 가 RePoE parser 리소스 cache miss 를 직접 fetch 하지 않는 점이었다.
- PR-19.18 변경 후 Items custom create / paste 경로는 현재 UI 언어를 `localeHint` 로 넘긴다. `pob:items-parse-copy-text` / `pob:items-parse-and-add` 는 RePoE base item, item class, unique, stat translation 리소스를 English/Korean 양쪽으로 fetch/cache 한 뒤 parser data 를 구성한다. 변환 실패 시 기존처럼 `Unmapped Korean item line: ...` 오류로 Lua 에 한국어 stat line 을 보내지 않는다.
- 등록된 custom item option 표시는 `translateItemsSnapshot()` 가 `snapshot.items` / `snapshot.sharedItems` 에 RePoE overlay 를 적용하는 기존 경로를 유지한다. 따라서 생성 직후 새 snapshot 도 현재 언어 기준 표시 번역을 다시 탄다.
