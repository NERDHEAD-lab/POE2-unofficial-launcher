> 상위 문서: [../pob-handoff.md](../pob-handoff.md)

## 목표

`docs/check/**` 의 Imported Build2 캡처와 PoB 원본 Lua/source snapshot 을 기준으로 Tree / Skills / Items / Calcs / Party 탭의 표시 데이터, 라벨, 툴팁, 빈 값 표현을 전수 비교하고, wrapper 가 PoB 원본과 다른 데이터를 보여주는 지점을 보정한다.

UI 레이아웃 개선은 허용하지만 표시되는 원본 데이터, option value, action payload, blank display 의미는 바꾸지 않는다.

계획 문서 관리 규칙에 따라 이 문서는 코드 커밋에 포함하지 않고 unstaged 상태로 둔다.

## Context Notes

- [x] PR-11.1 audit: Tree/Skills/Items는 rich hover tooltip payload가 현재 계약에 없음. Calcs/Party는 Imported Build2 기준 잔여 확인 중심.
- [x] Tree 원본 tooltip은 `PassiveTreeView.lua:AddNodeTooltip` 이 `Build.lua:AddStatComparesToTooltip` 를 호출해 stat diff를 만들고, path/dependent nodes/gold/tips를 같은 tooltip에 추가한다.
- [x] Tree tooltip 구현은 원본 `AddNodeTooltip` 를 재작성하지 않고 fake tooltip recorder에 기록하는 방식으로 PoB 원본 순서/문구를 보존한다.
- [x] Skills tooltip 구현은 원본 `GemSelectControl:AddGemTooltip` 와 `SkillsTab` 의 quality/enabled `tooltipFunc` 를 fake tooltip recorder에 기록한다. Imported Build2 현재 Calcs 선택 기준에서는 enabled 비교가 빈 tooltip일 수 있으며, 이는 원본 `AddStatComparesToTooltip` 의 diff 없음 조건을 따른다.
- [x] Items tooltip 구현은 원본 `ItemsTab.lua:AddItemTooltip` 를 fake tooltip recorder에 기록한다. DB mode 의 `Exclusive to`/source/variant/requirements/flavour text 와 custom/shared item equip stat difference 문구는 wrapper 재구성 없이 원본 순서로 payload에 포함된다.
- [x] Items UI 는 custom/shared/DB list hover 와 selected detail viewer에서 `pob.items.tooltip` payload를 우선 사용한다. Lua가 빈 tooltip을 반환하거나 API가 없으면 기존 summary 기반 fallback을 유지한다.
- [x] Calcs residual 확인: 원본 `CalcSectionControl.lua` 는 `formatCalcStr` 결과를 그대로 그리고, wrapper `calcs_snapshot()` 도 원본 `sectionList` 를 읽어 raw cell text를 보존한다. Imported Build2 회귀 테스트는 `All Types:/Physical:/Lightning:/Cold:/Fire:/Chaos:` header, blank `Added Min/Max` all-types cell, hit damage range, `Strength/Dexterity/Intelligence`, Life/Mana/Resist/Presence Radius/Attack Rate 값을 검증하고 `old:`, `ire:`, `haos:`, `-%`, `- to -` drift가 없음을 확인한다.
- [x] Party residual 확인: 원본 `PartyTab.lua` 의 `partyDestinations`, Import/Append/Clear/Show Advanced/Disable/Rebuild labels, 좌우 section labels가 `party_snapshot()` 계약에 반영되어 있다. Imported Build2 회귀 테스트는 notes, destination order, selected destination, empty text/simpleText, advanced toggle, append toggle, destination change, edit/clear, export support toggle을 검증한다. 추가 코드 수정 필요 없음.
