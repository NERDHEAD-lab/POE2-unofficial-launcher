# 다른 게임의 트위치 드롭스 표시

> 작성일: 2026-11-17 · 상태: PR 제출 준비 완료 · 브랜치: feat/cross-game-drops

PoE2를 보고 있을 때도 PoE1에서 진행 중인 드롭스를 ‘이달의 주요 소식’에서
확인할 수 있도록, ‘이벤트 알림 관리’에 기본 OFF인 표시 옵션을 추가한다.

- [Windows-pwsh] 기존 설정에 새 값이 없으면 선택한 게임 일정만 표시한다. 모달에서
  켠 값을 기존 이벤트 알림 설정에 저장하고, 다시 열어도 복원한다.
- [Windows-pwsh] ON이면 어느 게임의 진행 중인 드롭스든 아이콘을 활성화한다.
  동시에 진행 중인 서로 다른 행사는 각각 표시하고, 대표 링크는 선택한 게임을
  우선한다. 같은 공지에서 복제한 공통 일정은 한 번만 표시한다.
- [Windows-pwsh] 진행 중 일정이 없으면 가장 가까운 일정을 표시하며, 시작
  24시간 이내라면 기존 예정 아이콘과 해당 행사의 Twitch 링크를 제공한다.
  시작이 같으면 선택한 게임을 우선한다.
- [Windows-pwsh] 앱 내·Windows 알림, 보관함 할인, 피드 형식과 수집 동작을
  유지한다. 관련 Vitest, 전체 앱 테스트, lint, build:check를 확인한다.
- 독립 리뷰와 GitHub PR 확인까지 진행한다. 실제 앱을 열어 보는 사용자 검증은
  별도 확인 항목이다.

검증 결과

- Windows PowerShell, Node 24.18.0. 앱 Vitest 819개 통과, 폰트 샘플 의존
  테스트 9개 생략. 수집기 Node 테스트 73개 통과. lint와 build:check 통과.
- Vitest 전체 경로 실행 시 Node 전용 스위트도 탐색되므로 앱과 수집기는 각
  러너에서 별도로 확인했다.
- 독립 리뷰 1차 통과. 수정 지적 없음. 기본값, 설정 저장, 다른 게임 표시와
  링크 우선순위, 공통 행사 중복 제거, 기존 알림 범위를 확인했다.
